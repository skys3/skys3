# The ceph/s3-tests subset the SDK matrix runs (plan M1-25), one pytest
# node ID per line, from the commit pinned in Dockerfile. M7-01 completes
# the selection and publishes the compatibility matrix.
#
# Included: every test of s3tests/functional/test_s3.py and
# test_headers.py that passed against SkyS3 at that commit, grouped by
# feature, except those that pass only by accident: tests of rejected
# features (SSE-C, SSE-KMS, Object Lock, ACLs other than private, which
# answer an error the test happens to accept), POST object uploads (not
# supported; their tests expect an error), UploadPartCopy (plan M4-05),
# and three slow ones (the 1,000-key DeleteObjects limits and
# delimiter_not_skip_special, about 35 s together) whose features other
# tests here cover.
#
# Not included, and why (from a full run of both files):
# - Rejected features (design section 11): versioning, SSE-S3, SSE-KMS,
#   SSE-C, Object Lock, ACL grants and canned ACLs other than private,
#   object ownership other than BucketOwnerEnforced.
# - Features SkyS3 does not offer: bucket policies, public access blocks,
#   lifecycle configuration APIs, CORS, website, logging, POST object,
#   GetObjectAttributes, UploadPartCopy (plan M4-05), STS other than
#   AssumeRoleWithWebIdentity, IAM, SNS, S3 Select, and RGW extensions
#   (unordered listings, account usage, tenants, append).
# - SigV2 (refused by design), and conditional writes SkyS3 answers with
#   501 (If-None-Match with an ETag, both headers together, DeleteObject's
#   size and modification-time conditions).
# - Behaviour that differs from what these tests expect, left for M7-01
#   to check against AWS S3: `encoding-type=url` writes a space as `+`
#   (design section 11) where the tests expect `%20`, and encodes the V1
#   `Prefix`; an empty `Delimiter` is echoed; an empty continuation token
#   is refused; CreateBucket of an existing bucket answers
#   409 BucketAlreadyOwnedByYou; completing an already completed upload
#   answers 404 NoSuchUpload, where AWS S3 answers 200; a malformed
#   whole-object checksum on CompleteMultipartUpload answers
#   400 InvalidRequest, not BadDigest; ListBuckets ignores MaxBuckets and
#   Prefix; a completion that lists part 1 twice, once with the ETag of
#   an upload of it replaced since, answers InvalidPart
#   (multipart_resend_first_finishes_last).
